## 💻 Getting Started Locally

To run this project on your local machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Akshit501/akshitnegi.git
   cd akshitnegi
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port shown in terminal) to view the portfolio.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📌 Setting Up the Website Link on GitHub

To display the clickable link directly at the top of your GitHub repository:
1. Go to your repository on GitHub: [`https://github.com/Akshit501/akshitnegi`](https://github.com/Akshit501/akshitnegi)
2. In the right-hand sidebar under **About**, click the ⚙️ (gear icon).
3. In the **Website** field, enter your live portfolio link (e.g. `https://akshitnegi.vercel.app` or your custom domain).
4. Click **Save changes**.
